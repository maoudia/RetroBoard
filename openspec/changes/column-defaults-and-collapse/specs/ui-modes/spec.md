## ADDED Requirements

### Requirement: Progress bar switch at creation
The creation page SHALL show a "Show the progress bar" switch, on by default, in simple and in advanced mode.

#### Scenario: Simple mode
- **WHEN** Alice opens the creation page in simple mode
- **THEN** the switch is shown, on, with a one-line hint of what it controls

#### Scenario: Advanced mode
- **WHEN** Alice switches to advanced mode
- **THEN** the switch is shown at the same place with the same state
