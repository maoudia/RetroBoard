# Proposal

> **Shelved on 2026-11-19.** The project moved from AGPL-3.0-only to the PolyForm Noncommercial License 1.0.0 and closed outside contributions ([ADR-0040](../../../docs/adr/0040-polyform-noncommercial-source-available-license.md)). The monetization it describes (paid tiers and entitlements) is not planned: the project is free for noncommercial use and commercial rights are reserved to the owner. Its tasks already delivered (LICENSE, NOTICE, the source link) stay. No task of this change is planned; the text below is kept as it was written.

## Why

The owner wants a cheap SaaS with advanced features and themes unlocked for paying teams, a free tier that covers a real retro, an open source license (AGPL-3.0) that discourages closed resale, and no server or storage to manage subscriptions.

## What Changes

- License the code under AGPL-3.0-only with NOTICE (earlier commits remain MIT up to tag `last-mit`), a commercial license offer and a CLA for external contributions.
- Plans: Free, Pro, Team, one-off packs (docs/PLAN.md 13.2).
- Checkout and subscriptions through Polar (Merchant of Record) with license keys.
- Stateless `/license/redeem` endpoint: validates a license key with Polar and returns a signed entitlement token (Ed25519, 7 days).
- Relay enforces plan limits from the token (participants, session length, TURN); premium packs served only with a valid token.
- Pricing, legal notice, privacy, terms and refund information pages.

Out of scope: customer accounts, invoices generated by us (the MoR issues them).

## Capabilities

### New Capabilities

- `entitlements`: plans, license redemption, signed entitlement tokens and enforcement without storage.

### Modified Capabilities

None.

## Impact

- `apps/relay` (redeem endpoint, token verification), web settings and pricing pages, Worker secrets (`ENTITLEMENT_SIGNING_KEY`, `POLAR_ORG_ID`).
- Free-plan budget: one request per redemption, cached client-side for 7 days.
