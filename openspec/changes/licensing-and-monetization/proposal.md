# Proposal

## Why

The owner wants a cheap SaaS with advanced features and themes unlocked for paying teams, a free tier that covers a real retro, no resale of the product by others, and no server or storage to manage subscriptions.

## What Changes

- License the code under FSL-1.1-ALv2 (Fair Source); add NOTICE explaining that earlier releases remain MIT.
- Plans: Free, Pro, Team, one-off packs (docs/PLAN.md 13.2).
- Checkout and subscriptions through Polar (Merchant of Record) with license keys.
- Stateless `/license/redeem` endpoint: validates a license key with Polar and returns a signed entitlement token (Ed25519, 7 days).
- Relay enforces plan limits from the token (participants, session length, TURN); premium packs served only with a valid token.
- Pricing, legal notice, privacy, terms and refund information pages.

Out of scope: customer accounts, invoices generated by us (the MoR issues them).

## Capabilities

### New Capabilities

- `entitlements`: plans, license redemption, signed entitlement tokens and enforcement without storage.

### Modified Capabilities

None.

## Impact

- `apps/relay` (redeem endpoint, token verification), web settings and pricing pages, Worker secrets (`ENTITLEMENT_SIGNING_KEY`, `POLAR_ORG_ID`).
- Free-plan budget: one request per redemption, cached client-side for 7 days.
