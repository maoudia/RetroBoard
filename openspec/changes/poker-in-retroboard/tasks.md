# Tasks

Sequence (owner decision of 2026-11-21): (1) the actual poker is finished first (group 6 of `poker-design-v2`, another worker); (2) `poker-deck-studio`; (3) this change; (4) `board-estimation-phase`. This change starts when `poker-deck-studio` has merged its groups 1 to 4 (the cards, the model, the builder and the gallery are what it reuses). Group 7 starts when the first groups of `board-estimation-phase` (its domain and the badge on a note) have merged. The released text of `poker-design-v2` and `scrum-poker` is not rewritten ahead of the code: the pull request of a task amends the older text it replaces (design, "What this replaces once it is implemented").

Order: what the owner sees first comes first, so the theme (group 1), the creation flow (group 2), the library and the share panel (group 3) and the export (group 4) go before the shared session (group 5), the room tools (group 6), the link with the board (group 7) and the gates (group 8). Groups 1 to 4 ship on the current client, so the owner-visible parts do not wait for group 5. One group is one pull request; a task is about two hours of one agent session. Every task keeps `pnpm e2e:core` green (the poker spec is in the core gate), lands its own tests and its i18n keys in fr and en, and corrects the guide chapter and `docs/DEVELOPMENT.md` in the same pull request (AGENTS.md). The design language rule applies to every task: the product's own components, classes, tokens and patterns, named in "Shared components reused" of `design.md`; a task that touches a poker surface with its own look moves it onto the shared one in the same pull request. Screenshots go in the pull request, never in the repository; `before/` stays until the change is archived.

Verification vocabulary: "screenshot review" is a review of the real page at the sizes named against the wireframes of `design.md`, in light and dark, by the agent and again in the pull request; "axe" is axe-core in light and dark (`tests/e2e/helpers.ts`); "pseudo-locale" is `?lang=pseudo` (and French) at 360, 390, 768 and 1440 px; "bundle budget" is `scripts/check-bundle-size.mjs` (entry 56.5 kB, total 500 kB); "token audit" is `apps/web/test/design-tokens.test.ts`; "relay contract tests" are the existing relay and ledger tests, which stay unchanged.
