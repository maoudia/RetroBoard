## ADDED Requirements

### Requirement: Hide for now for every role
"Hide for now" in the column menu SHALL hide the column in the user's own view regardless of role, including when every participant is facilitator.

#### Scenario: Open facilitation
- **WHEN** everybody is facilitator and a user chooses "Hide for now" on a column
- **THEN** that column disappears from her view and can be shown again from the same menu
