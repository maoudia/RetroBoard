# Tasks

Sequence (owner decision of 2026-11-21): (1) the actual poker is finished first (group 6 of `poker-design-v2`); (2) `poker-deck-studio`; (3) `poker-in-retroboard`; (4) this change. It is an additive follow-up: the pull request of a task amends the older text it replaces (design, S12). Group 1 can start when `poker-deck-studio` has merged its groups 1 to 4 (the cards, the model, the builder, the gallery) and `poker-in-retroboard` its groups 1 and 4 (theme parity is free on a board; the export door is the one used here); the later groups wait for `poker-in-retroboard`'s shared session only where they say so. ADR-0045 is proposed with this change; it is accepted by the owner before group 1 merges, and a task that finds the decision wrong writes a new ADR rather than editing it.

Order: the end-to-end path comes first, as the owner asked: **import the tickets, start the phase, vote one ticket, the badge on the note, the export** (group 1, four tasks, each a vertical slice that works on its own), then the queue and the exits (2), joining, roles and durability (3), the phase view on every screen (4), the results (5) and the gates (6). One group is one pull request; a task is about two hours of one agent session. Every task keeps `pnpm e2e:core` green and the existing ledger, relay and board tests unchanged (they gate the shared fold), lands its own tests and its i18n keys in fr and en, and corrects the guide chapter and `docs/DEVELOPMENT.md` in the same pull request (AGENTS.md). The design language rule applies to every task: the board's own components, classes, tokens and patterns, and the standalone poker's cards, table, hand and results, named in `design.md`; no new bar, menu, dialog, button, chip or panel. Screenshots go in the pull request, never in the repository.

Verification vocabulary: "screenshot review" is a review of the real page at the sizes named against the wireframes of `design.md`, in light and dark, by the agent and again in the pull request; "axe" is axe-core in light and dark (`tests/e2e/helpers.ts`); "pseudo-locale" is `?lang=pseudo` (and French) at 360, 390, 768 and 1440 px; "bundle budget" is `scripts/check-bundle-size.mjs` (entry 56.5 kB, total 500 kB); "token audit" is `apps/web/test/design-tokens.test.ts`; "the board tests" are the existing ledger, reducer, relay and board e2e tests, which stay unchanged.
