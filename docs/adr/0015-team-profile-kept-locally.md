# Team profile kept locally

## Context and Problem Statement

Teams want a name, a sprint counter and their action history across retros.

## Considered Options

* Team profile kept locally by the facilitator, exportable
* Server-side team space

## Decision Outcome

Chosen option: "Team profile kept locally by the facilitator, exportable", because it keeps the zero-storage promise.

### Consequences

* Good, because no account, no server data
* Bad, because the profile lives on one device unless exported
