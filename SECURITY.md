# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/maoudia/RetroBoard/security/advisories/new).
Do not open public issues for security problems.

- Scope: retroboard.maoudia.com, the Worker and relay, the web app, the MCP server.
- We aim to acknowledge reports within 5 working days.
- Board content is end-to-end encrypted once rooms use protocol v2; reports about key handling,
  the relay, CSP bypasses or cross-board access are especially welcome.
